#Rules 
# Actions d'espionnage

Les actions d'espionnage entrent dans 3 catégories, qui ont chacune un jeton associé : 
1. *Violence* : course, nage, saut, combat au corps à corps ou à distance, intimidation...
2. *Influence* : séduction et persuasion, fouille, perception, recherche...
3. *Secret* : filature et surveillance, infiltration, dissimulation, bluff et mensonge...

Les jetons de *Confiance* peuvent s'utiliser à la place de n'importe quel autre jeton.
## Gagner des jetons
 
- Un jeton est attribué chaque matin à un agent en fonction de son rôle
- Un jeton peut être gagné en échange d'une demi-journée (matin, après-midi, soir)
- Un jeton est gagné en cas de réussite critique sur un risque
- Si un agent est *digne de confiance* (n'a pas utilisé de jeton de confiance sur la journée), il peut gagner un jeton de confiance à la fin de la journée sur un coin flip.
# Risque

Pour faire un risque de type violence, influence ou secret, un jeton correspondant est mis en jeu, sauf si le Narrateur demande à l'agent de faire le risque (risque réactionnel).

**Le seul de réussite est de 9,** avant application des avantages/désavantages. 

| Avantages                 | Désavantages  |
| ------------------------- | ------------- |
| Trait positif             | Trait négatif |
| Réalisations              | Faiblesses    |
| Etat positif              | Etat négatif  |
| Nom de code               |               |
| Rôle                      |               |
| Couverture                |               |
| Matériel de soutien       |               |
| Matériel de qualité       |               |
| Jeton supplémentaire (+2) |               |
Sur un risque antagoniste, i.e. où un PNJ s'oppose à l'agent, les niveaux de VIS sont comparés : Violence vs Violence et Influence vs Secret. La différence est ajouté aux avantages ou désavantages suivant qu'elle soit en faveur de l'agent ou du PNJ.

Le Narrateur peut ajouter des avantages/désavantages en fonction de la situation à sa discrétion.

**Résultat** : 
- As : *réussite critique*. L'agent gagne un jeton supplémentaire de confiance en plus de récupérer son jeton.
- Supérieur strictement au seuil : *réussite*. L'agent récupère son jeton.
- Egal au seuil : *sur le fil*. L'agent réussit son action mais perd son jeton.
- Inférieur au seuil : *échec*. L'agent perd son jeton.
- Joker : *échec critique*. L'agent perd son jeton, plus un jeton supplémentaire de confiance.
