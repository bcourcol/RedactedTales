Le rôle de l'agent est sa profession d'agent secret, le rôle qu'il remplit à l'agence. A ne pas confondre avec sa couverture. Les rôles sont également associés aux trois vertus principales de l'espionnage, qui sont la Violence, l'Influence et le Secret. 
# Fonctions

Le rôle a plusieurs fonctions dans le jeu : 
- Donne un avantage de départ. 
- Donne un avantage si invoqué pour un [[2.2. Risques|risque]].
- Au début de chaque jour, donne un [[2.1. VIS|jeton]] du type du rôle.
- Permet d'utiliser un pouvoir, **à raison d'une fois par jour,** en échange d'un jeton du type du rôle
# Difficulté

Un rôle n'est pas un carcan qui empêche l'agent de faire certaines actions, mais qui seulement peut lui donner un avantage dans certaines situations. Cet avantage est plus ou moins facile à invoquer suivant les situations, ainsi certains rôles sont un peu plus faciles que d'autres. Le niveau de difficulté et indiqué dans la liste des rôles ci-dessous.
# Liste des rôles

## Violence

| Rôle             | Difficulté | Pouvoir                                                                          | Avantage de départ |
| ---------------- | ---------- | -------------------------------------------------------------------------------- | ------------------ |
| Agent de terrain | Facile     | Repioche en cas d'échec à un risque                                              | Aucun              |
| Commandant       | Moyen      | Donne un avantage sur le prochain risque de tous les agents travaillant ensemble | Arme de qualité    |
| Médecin          | Difficile  | Ajoute ou retire un [[3.4. Etats\|état]] à un agent                              | Trousse de secours |
## Influence

| Rôle              | Difficulté | Pouvoir                                    | Avantage de départ                   |
| ----------------- | ---------- | ------------------------------------------ | ------------------------------------ |
| Officier traitant | Facile     | Découvre le type de mémento d’un PNJ       | 1 indic                              |
| Agent de liaison  | Moyen      | Gagne un jeton de confiance                | Passeport diplomatique               |
| Analyste          | Difficile  | Obtient une réponse oui/non à une question | Une information bonus sur l'intrigue |
## Secret

| Rôle       | Difficulté | Pouvoir                                                                                   | Avantage de départ                 |
| ---------- | ---------- | ----------------------------------------------------------------------------------------- | ---------------------------------- |
| Clandestin | Facile     | Gagne un trait positif pour la journée (ne peut être le compémentaire d'un trait négatif) | Couverture dans un organe étatique |
| Pilote     | Moyen      | Réussit automatiquement un risque réactionnel                                             | Véhicule                           |
| Ingénieur  | Difficile  | Crée du matériel custom                                                                   | Equipement spécialisé au choix     |
